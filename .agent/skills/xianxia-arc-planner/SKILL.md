# xianxia-arc-planner

## Tujuan

Menjaga novel memiliki arah, payoff, dan eskalasi tanpa menjadikan pembaca sebagai co-writer. Rencana bersifat fleksibel, rahasia, dan berorientasi perubahan state.

## Gunakan ketika

Gunakan secara internal saat memulai kitab, menutup arc, atau ketika arah cerita perlu direkonstruksi; jangan menampilkan outputnya kepada pembaca mode default.

## Jangan gunakan ketika

- tahap pipeline tidak sesuai;
- input wajib belum tersedia;
- tugas dapat diselesaikan oleh validator deterministik sederhana;
- pengguna hanya meminta informasi faktual di luar penulisan novel.

## Input wajib

- story constitution;
- hard/soft preferences;
- committed canon;
- unresolved promises;
- character arcs;
- progression ceiling;
- target range jumlah bab;
- feedback arc sebelumnya.

## Output wajib

Rencana kitab rahasia:
- central dramatic question;
- start state dan target end state;
- 3–6 movement;
- promise/payoff map;
- mystery ledger;
- antagonist pressure;
- character change;
- progression budget;
- contingency branches;
- prohibited reveals.

## Workflow

1. Rumuskan pertanyaan dramatis kitab.
2. Tentukan perubahan permanen pada akhir kitab.
3. Susun movement berdasarkan sebab-akibat, bukan daftar kejadian.
4. Beri setiap movement tekanan, pilihan, konsekuensi, dan state change.
5. Jadwalkan setup dan payoff.
6. Atur progression budget agar kenaikan kekuatan tidak menghapus konflik.
7. Simpan 1–3 contingency branch untuk respons terhadap state yang berubah.
8. Tandai semua rahasia dan reveal condition.
9. Audit repetisi trope terhadap kitab sebelumnya.

## Aturan keras

- Output hanya untuk sistem internal.
- Jangan mengunci semua detail; sisakan ruang discovery.
- Twist wajib memiliki setup.
- Jangan membuat karakter bertindak melawan sifatnya hanya demi milestone.
- Satu kitab harus menyelesaikan konflik utama meski misteri besar dapat berlanjut.
- Jangan memakai kenaikan realm sebagai satu-satunya klimaks.

## Checklist selesai

- [ ] Pertanyaan dramatis jelas.
- [ ] Akhir kitab mengubah dunia/karakter.
- [ ] Setup mendahului payoff.
- [ ] Antagonis memiliki strategi, bukan sekadar kekuatan.
- [ ] Progression memiliki harga.
- [ ] Tidak ada spoiler di output publik.
- [ ] Trope utama tidak mengulang kitab sebelumnya tanpa transformasi.
