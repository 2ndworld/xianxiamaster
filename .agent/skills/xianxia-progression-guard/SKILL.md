# xianxia-progression-guard

## Tujuan

Menjaga progression fantasy terasa earned. Skill ini menghasilkan diagnosis dan patch constraint, bukan menulis ulang bab secara penuh.

## Gunakan ketika

Gunakan untuk mengaudit pertarungan, terobosan, teknik, artefak, sumber daya, dan kemenangan lintas realm.

## Jangan gunakan ketika

- tahap pipeline tidak sesuai;
- input wajib belum tersedia;
- tugas dapat diselesaikan oleh validator deterministik sederhana;
- pengguna hanya meminta informasi faktual di luar penulisan novel.

## Input wajib

- draft;
- power-system canon;
- character state;
- inventory;
- injuries;
- techniques;
- progression budget;
- exception rules.

## Output wajib

Audit terstruktur:
- hard violations;
- soft plausibility issues;
- cross-realm justification;
- cost and consequence check;
- required fixes;
- maximum safe patch scope.

## Workflow

1. Identifikasi semua penggunaan kemampuan.
2. Cocokkan prasyarat, level, biaya, cooldown, dan kondisi tubuh.
3. Periksa perpindahan artefak dan sumber daya.
4. Evaluasi kemenangan lintas realm berdasarkan informasi yang telah disiapkan.
5. Periksa apakah terobosan memiliki proses dan konsekuensi.
6. Periksa apakah teknik baru menggantikan strategi secara instan.
7. Bedakan pelanggaran canon dari kejutan yang sah.
8. Rekomendasikan patch terkecil.

## Aturan keras

- Realm bukan angka tunggal; pertimbangkan matchup, lingkungan, persiapan, artefak, dan informasi.
- Namun pengecualian wajib telah disiapkan atau dijelaskan.
- Jangan merasionalisasi deus ex machina setelah kejadian.
- Luka dan biaya tidak boleh hilang pada scene berikutnya.
- Jangan menaikkan level hanya agar klimaks terasa besar.

## Checklist selesai

- [ ] Semua kemampuan memiliki sumber.
- [ ] Semua biaya tercatat.
- [ ] Lompatan realm terjustifikasi.
- [ ] Inventory konsisten.
- [ ] Cedera memengaruhi tindakan.
- [ ] Canon delta progression eksplisit.
