# XianxiaMaster — Narrative Skill Pack v0.2

Skill orkestrator utama untuk menghasilkan novel xianxia serial personal dengan:

- narasi dan dialog bahasa Indonesia;
- istilah dunia bahasa Inggris kanonik;
- canon pembaca dan canon rahasia yang terpisah;
- perencanaan cerita tanpa membocorkan spoiler;
- audit continuity, progression, terminology, dan reader experience;
- commit canon hanya setelah seluruh hard gate lulus.

> **Indonesian prose, English world terminology.**

Lihat `SKILL.md` untuk skill utama dan `.agent/skills/` untuk sub-skill modular.
